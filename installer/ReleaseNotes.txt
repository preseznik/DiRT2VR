DiRT2VR 0.17.19 - Experimental diagnostic build

Investigating direct-launch freezes
This build adds more detail to the optional startup log: it shows whether the game finds a career and where automatic loading stops. It does not change or replace your saved career and is not a confirmed fix for the freeze.

The previous build passed Fresh-profile Practice and Return to menus on PC3080. The misleading game-still-running message is also resolved there. Current game career still needs investigation.

Testing
Keep diagnostic logging enabled, select Current game career and launch desktop Practice. If it freezes, leave it for at least 15 seconds before closing, then share that run's trace.log. No memory dump is needed. Turn logging off after testing.

Cockpit wheel jitter is still under investigation. This build does not claim a steering-animation fix.

This installer is for local testing; it has not been published as a release.
