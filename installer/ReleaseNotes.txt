DiRT2VR 0.17.24 - Experimental test build

Up/Down navigation for direct-event menus
The pause and finish menus in Direct practice and Race now use Up/Down to select their vertical choices, instead of requiring Left/Right.

Restart and Return to menus keep their existing behavior. This build retains the accepted Hammada scenery and cockpit-steering improvements.

Automated menu and recovery checks passed. In-game navigation confirmation is still pending.

This installer is for local testing and has not been published.
