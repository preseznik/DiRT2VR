DiRT2VR 0.17.18 - Experimental test build

Direct-launch compatibility
Fix a missing GFWL compatibility step in desktop Practice/Race with optional features off. This is a candidate for the reported startup freeze, not yet a confirmed fix on PC3080. Your existing career remains unchanged.

Launcher recovery
Avoid an unnecessary process-access check while waiting for the game. Previous launch errors no longer claim a closed game is still running.

Cockpit steering
The optional steering correction is still under investigation: wheel/hand jitter has been reported. It remains off by default and does not offer full 540/900-degree wheel matching.

Testing
Enable Settings > Enable diagnostic logging, save, then retry desktop Practice with Current game career. The existing logs now include profile-loading checkpoints and steering activation details. No memory dump is required. Turn logging off after testing.

This is a local testing installer, not a published release.
